  1. Запусти Minecraft Java Edition
    Выбери версию 1.20.1.
  2. Добавь новый сервер
    Открой «Сетевая игра» → «Добавить».
  3. Укажи адрес и подключись
    После запуска проекта здесь будет рабочий адрес.

ПРАВИЛА И ПОМОЩЬ

Чтобы всем было уютно

Уважай игроков и их постройки

Пример правил: не ломай чужие постройки, не забирай вещи без разрешения и согласовывай строительство рядом с соседями.

Играй честно

Пример правил: читы, дюпы и использование ошибок ради преимущества запрещены. Найденную ошибку стоит сообщить администрации.

Как связаться с командой?

Контакты появятся перед открытием проекта. Сейчас это демонстрационная версия сайта, заявки и сообщения не отправляются.

Нужен ли отдельный лаунчер?

Для основного мира в этой концепции достаточно Minecraft Java Edition. Для технического мира инструкция будет опубликована отдельно.
